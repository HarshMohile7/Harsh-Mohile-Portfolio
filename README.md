## Run locally

1.  Download or clone this repository.
2.  Keep `index.html` and the `certificates/` folder in the same
    directory.
3.  Open `index.html` in a web browser.

No build tools, package installation, or framework setup are required.

## Deploy with GitHub Pages

1.  Create a new repository on GitHub. For a personal site, you can name
    it `your-username.github.io`. Alternatively, use any repository name
    for a project site.
2.  Upload the website files to the repository's **root**:
    -   `index.html`
    -   `certificates/iit-kanpur-cybersecurity.png`
    -   `certificates/microsoft-sc900.png`
    -   `certificates/csi-appreciation.png`
    -   `certificates/sutherland-training.png`
    -   `README.md`
3.  On GitHub, open the repository and go to **Settings → Pages**.
4.  Under **Build and deployment**, select **Deploy from a branch**.
5.  Choose the `main` branch and the `/(root)` folder, then click
    **Save**.
6.  Wait for the deployment to finish. GitHub will display the published
    website URL in the Pages settings.

For a project repository, the published URL usually follows this format:

`https://your-username.github.io/repository-name/`

For a personal site repository named `your-username.github.io`, it
usually follows:

`https://your-username.github.io/`
